# Event Management and Booking System

## Overview
The Event Management and Booking System is a web application built using ASP.NET MVC that allows users to manage events and book venues. The system provides a user-friendly interface for administrators to manage events, bookings, and users, as well as a booking system for customers to book events.

### Features

- Event Management: Administrators can create, edit, and delete events.
- Booking System: Customers can book events and manage their bookings.
- User Management: Administrators can create, edit, and delete users.
- Booking Reports: Administrators can generate reports on bookings and revenue.
- Security: The system uses HTTPS encryption to secure user data.

### Technology Stack
- ASP.NET MVC: The system is built using ASP.NET MVC, providing a clean and efficient architecture for the application.
- Entity Framework: The system uses Entity Framework to interact with the database.
- SQL Server: The system uses SQL Server as the database management system.
- Bootstrap: The system uses Bootstrap for styling and layout.
